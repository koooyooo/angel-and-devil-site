# angel-and-devil-site

Project site for **Angel & Devil** — an angel 😇 and a devil 😈 read your note and banter about it.

- Obsidian plugin: https://github.com/koooyooo/angel-and-devil-obsidian
- Agent Skill: https://github.com/koooyooo/dot-agent-angel-and-devil

Plain static HTML (no build step), served by GitHub Pages from the root of `main`.
Pages live under `ja/` (Japanese) and `en/` (English). The root `index.html` sends visitors to one of them
by browser language; the root `getting-started.html` and `legal.html` only redirect old links to `ja/`.

This repository is generated by an export from a private monorepo; please do not commit here directly —
open an issue instead.
