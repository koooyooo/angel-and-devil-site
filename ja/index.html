Get started

ふたつの使い方

普段ノートを書いている場所に合わせて選べます。どちらも Gemini API キー（Google AI Studio で無料取得可）を使います。

Obsidian ユーザー向け

Obsidian プラグイン

ノートのヘッダーにある 😇😈 ボタンを押すだけ。上のデモと同じモーダルで、ふたりがセリフを交わします。

  • 選択範囲だけを対象にした掛け合い
  • ノート末尾への保存と「ひとこと返す」
  • 2 話者の音声読み上げと掛け合いの記憶

おすすめは BRAT での導入です。Windows・macOS・Linux・iOS・Android のどれでも、Obsidian の中だけで入れられて、自動で更新されます。BRAT を使わない手動の手順もあります。

Features

Obsidian プラグインでできること

書いて、読ませて、少し言い返す。

🎬

アニメーション付きモーダル

クリック / Space で 1 セリフずつ。スキップで一括表示、もう一度で再生成。

✂️

選択範囲だけ

テキストを選んでから実行すると、その部分だけを対象に掛け合います。

💾

ノートに保存

掛け合いを引用ブロックとしてノート末尾に追記。あとから読み返せます。

💬

ひとこと返す

掛け合いの後にひとこと返信すると、悪魔が先に応え、天使が締めます。

🔊

2 話者の読み上げ

Gemini TTS で天使と悪魔が別々の声に。声に合わせてキャラクターも動きます。

🧠

掛け合いの記憶

ふたりがメモを残し、過去に触れたり同じ指摘を繰り返さないように話します。

Privacy

プライバシー

ノートは、あなたが掛け合いを始めたときにだけ送信されます。

  • 掛け合いを開始したときだけ、ノートの本文（または選択範囲）がご自身の API キーで Google Gemini API に送信されます。それ以外のタイミングで通信はしません。
  • フロントマター（YAML）や、過去に保存した掛け合いブロックは送信前に自動で除外されます。
  • 音声読み上げ（既定でオフ）を使うと、生成された掛け合いテキストが Gemini TTS に送信されます。音声データはメモリ上にのみ保持されます。
  • 記憶（既定でオフ）は Vault 内の普通のノートとして保存され、外部のサーバーには残りません。
