Features

What the Obsidian plugin does

Write, let them read, talk back a little.

🎬

Animated modal

One line per click or Space. Skip to show all, or regenerate.

✂️

Selection only

Select text first and the banter covers just that part.

💾

Save to note

Append the banter as a quote block at the end of the note.

💬

Talk back

Reply once after the banter: the devil answers first, the angel closes.

🔊

Two-voice read-aloud

Gemini TTS gives each character a voice, and the characters move with it.

🧠

Memory

They keep notes, refer back to past banter, and avoid repeating the same point.

Privacy

Privacy

Your note is sent only when you start a banter.

  • Only when you start a banter, the note body (or selection) is sent to the Google Gemini API using your own API key. Nothing is sent at any other time.
  • Frontmatter (YAML) and previously saved banter blocks are stripped before sending.
  • With read-aloud on (off by default), the generated banter text is sent to Gemini TTS. Audio is kept in memory only.
  • Memory (off by default) is stored as ordinary notes inside your vault, not on any external server.
